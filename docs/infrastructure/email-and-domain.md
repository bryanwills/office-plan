# Email & Domain Decision

## The two decoupled axes

Email/productivity platform and cloud infrastructure platform don't have to match. You can run business email on one and infra credits/compute on a completely different provider.

## Email / productivity: Google Workspace vs. Microsoft 365

| | Google Workspace | Microsoft 365 |
|---|---|---|
| Admin familiarity | New console to learn | Already deeply familiar (Exchange Online/EAC/PowerShell from day job) |
| Entry pricing | Similar ballpark (Starter tier) | Similar ballpark (Business Basic) |
| Dev tooling integration | Slight edge for some dev-adjacent tooling | Native fit if pairing with Azure |
| Practice value | None specific to existing skillset | Doubles as hands-on practice for Purview/Exchange documentation habits already in use |

**Recommendation:** Microsoft 365 Business Basic — leverages existing admin expertise directly, zero new learning curve, and pairs naturally with the Azure credit program below.
