# Cloud Credits & Startup Programs

## Decision: Apply to Microsoft for Startups Founders Hub

Status: **Action item — not yet applied**

### Why this over a standalone GCP trial

- GCP's $300 trial is a generic 90-day new-account trial, not a business program — expires regardless of usage.
- Microsoft for Startups Founders Hub is self-serve, requires **no VC/accelerator referral** for the entry tier, and is open to bootstrapped solo founders.
- Realistic self-serve credit at entry: ~$1,000 instant + $4,000 after verification (~$5,000 total) — the frequently-advertised "$150K" headline requires an Investor Network referral this LLC won't have as a bootstrapped single-member entity.
- Bundled benefits regardless of Azure usage level: free Azure Support, 20 GitHub Enterprise seats, Visual Studio Enterprise, Microsoft 365 Business Premium, Azure OpenAI Service access. The GitHub Enterprise + M365 bundle alone is worth the application.
- Aligns with existing Azure/Ubuntu fleet management experience — fastest platform to be productive on operationally.

### Application checklist

- [ ] Sign up at [startups.microsoft.com](https://startups.microsoft.com) — needs a professional website/company details (docs site or bigbraincoding.com works for this)
- [ ] LLC formation should be complete first (business verification is part of the process)
- [ ] Review takes ~1–7 business days
- [ ] Base benefits unlock immediately at signup; higher tiers require partner verification (not needed for the base tier)

### Note

GCP account can still be created separately at zero cost/commitment if Google infra is wanted alongside Azure later — these programs aren't mutually exclusive.
